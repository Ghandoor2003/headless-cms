# Headless CMS

This is a headless Content Management System (CMS) built with **Headless-CMS-Express** and **CMS-Admin (Next.js 15)**. It provides a flexible API and an admin interface for managing content in a headless architecture.

## Features
- **Headless CMS Backend**: Built using Express to serve content as a RESTful API.
- **Admin Dashboard**: Built with Next.js 15, allowing for easy content management and interactions.
- **Customizable**: Easily extendable to support various content types and data structures.
